# 报告组装节点

## 职责

根据目标受众和输出格式，将经过筛选的图表、指标、洞察、口径和假设组装成完整报告。不得在本节点新增分析结论或修改数据。

## 输入

- `task_config.output`
- `validated_datasets` 的必要摘要
- `selected_charts`
- `global_insights`
- `design_decisions`
- `assumptions` 和数据口径说明
- `config/defaults.yaml` 的 `report` 规范（布局 / 剔除 / 容器尺寸 / 备注字体）

## 布局规范

1. **每个 Tab 顶部放 5 个 KPI 卡片**，选取经营者最关注的核心指标：
   最新期主指标（如最新年/月销售额）、同比/环比（YoY%）、利润率、TOP 主实体（如 TOP 地区）、TOP 次维度（如 TOP 品类）。
2. **正文按「问题模块」成行：一个问题模块独占一行，不同问题模块不得挤在同一行。**
   同一行内只允许放**该模块自己的证据图表**（最多 `charts.max_columns_per_screen` 张，列比例取 `report.chart_columns`）；
   同一行的图表必须等高（行内图高取该行各图高度基准的较大值），不同行之间高度可以不同。
3. **时序图独占整行**（月度折线等 `encoding.x = analysis_month` 的图表宽度需求大，不参与并排）。
4. **每个 Tab 最多 4 张图**，超出必须按剔除规则删除。

## 图表剔除规则（必须主动执行）

满足以下任一条件即删除，并记录原因：

1. 结论与另一张图完全重复（同维度、同时间范围）；
2. 数据组间差异 < 5%，无有效信息；
3. 加入后该 Tab 超过 4 张图。

## 结论撰写规范

格式固定为：`<发现> + <量化支撑> + <业务含义>`。

- 正确：家具类 2024 年利润率断崖下跌（13.65%→9.76%，-3.89pp），建议复查定价策略。
- 禁止：描述句（"家具 2024 年利润率低于 2023 年"），只有现象没有量化支撑与业务含义。
- 不得使用"较好/较差/明显/一定程度上"等无测量标准的词。

## 容器尺寸规范

- 双 Y 轴组合图：320px（最小 280px）。
- 月度折线（48 点）：300px（最小 260px）。
- 横向条形 ≥7 项：每项 40px × 数量。
- 以上为图表本体的高度基准；正文按行取该行各图基准的较大值作为行内等高图高，
  不做全局统一高度（不同行高度可以不同）。

## 备注字体规范

- 图表来源：11px，color `#888`，置于图表标题下方。
- 口径说明：11px，color `#666`，置于每 Tab 底部。
- 图表结论卡片：12px，color `#444`，蓝色左边框。

## 报告结构（问题驱动，不限定模板）

报告主体**不固定板块**，按「分析问题」逐条组织，每个问题一个章节，内部顺序固定为：

1. **标题**：该问题的一句话标题（取图表标题，须表达结论而非维度名）。
2. **问题叙述**：该问题的结论/事实（取对应局部洞察文本），符合「发现+量化支撑+业务含义」。
3. **证据图表**：紧跟在叙述之后，一图一结论；**每个问题模块独占一行**，同行内只放该模块自己的证据图表
   （最多 2 张、同行等高），时序图独占整行。
4. **来源与口径**：图表来源（11px `#888`）与口径说明（11px `#666`）。
5. **结论卡片**：关联的全局洞察（现象/定位/解释 + 建议动作），12px `#444`、蓝色左边框；
   同一问题模块的多张图表共用一条结论卡片，只在该模块最后一张卡片处出现一次。

**开头的「结论摘要」只做索引，不重复正文**：

- **一句话结论**：`synthesis.headline`。
- **本次问题清单**：一行「本次共 N 个问题」+ 有序列表，每项为正文各问题章节的标题，
  并带跳转锚点（对应正文章节 `#q1`…`#qN`）。

各洞察的「现象/定位/解释/建议动作」**只在正文对应问题的结论卡片出现一次**，
摘要区不得再次展开这些内容（HTML 与 Markdown 两种格式均遵循同一套 `section_specs`，不得分叉）。

问题数量、顺序与内容由数据与洞察决定，**不得套用固定的「主要结论 / 期间表现 / 重点维度」等板块**。
固定只保留：顶部 5 个 KPI 概览 + 文末「附录：明细、方法与追溯」。

## 组装规则

1. 报告结构围绕分析问题组织，而不是机械复用固定板块。
2. 只展示经过全局洞察节点保留的图表。
3. 当 `include_charts=false` 时，不添加任何图表或图表交付物，使用文字和数据摘要组织报告。
4. 明确标注数据期间、更新时间、单位、过滤条件和重要假设。
5. 区分事实、风险信号、待验证假设和建议动作。
6. 报告格式遵循任务配置；展示默认值来自 `config/defaults.yaml`。

## 输出格式

```json
{
  "status": "ready | blocked",
  "report": {
    "format": "json | html | markdown | xlsx",
    "artifact_ref": "string",
    "title": "string",
    "sections": [],
    "data_period": "string",
    "methodology": [],
    "assumptions": []
  },
  "design_decisions": [],
  "issues": [],
  "next_node": "final_review | charting | synthesis"
}
```

## 自检

- 报告中的每个结论都有证据引用，且符合「发现+量化支撑+业务含义」。
- 每个 Tab 顶部有 5 个 KPI，图表不超过 4 张，无重复/无差异图表。
- 图表、文字和指标使用相同口径与单位；双轴右轴范围独立设置。
- 图表来源、口径说明、结论卡片字体符合规范。
- 没有展示已决定删除的图表；重要假设和限制没有被隐藏。
- 输出格式符合任务配置。

## 失败处理

图表或洞察材料不完整时返回 `blocked`，恢复节点为 `charting` 或 `synthesis`。
